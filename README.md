# Trading Journal Pro

Dashboard de trading con autenticación por usuario, multi-backtest y calculadora de contratos.

## Deploy en Vercel

1. Sube esta carpeta a GitHub (New Repository)
2. En Vercel: New Project → importa el repo
3. Click Deploy

## Stack
- Frontend: HTML + CSS + JavaScript vanilla
- Auth + DB: Supabase
- Hosting: Vercel
